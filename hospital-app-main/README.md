# Hospital App

Hospital management app.

## How to Operate

1. **To make the working database with example entries:**  
    a) Uncomment the last three lines in `models.py` and run it as a Python file.
       (Just uncomment the three lines before the last three lines if you just want to add the admin.) 
    c) Re-comment the same lines and save the `models.py` file.

2. **To run the app:**  
   Run the `app.py` file as a Python file and go to `http://localhost:5000/` in your browser
